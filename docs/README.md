# Dokumentasi Teknis

## Pembahasan Algoritma ANN

Dokumen lengkap pembahasan implementasi Artificial Neural Network (ANN) untuk sistem prediksi penjualan menu harian Restoran Hokben.

📄 **File**: [Pembahasan_Algoritma_ANN_Hokben.docx](./Pembahasan_Algoritma_ANN_Hokben.docx)

### Isi Dokumen

Dokumen ini mencakup pembahasan mendalam tentang:

- **4.1 Data Sampel** - Dataset yang digunakan untuk training model
- **4.2 Langkah-Langkah Algoritma ANN** - Detail implementasi algoritma meliputi:
  - Arsitektur Neural Network (12-20-1)
  - Hyperparameter dan konfigurasi
  - Normalisasi dan preprocessing data
  - Forward propagation
  - Backpropagation dan weight update
  - Proses training dan evaluasi
- **4.3 Contoh Kasus Prediksi** - Studi kasus prediksi real dengan input dan output
- **4.4 Perbandingan dengan Metode Lain** - Analisis komparatif dengan metode prediksi lainnya
- **4.5 Kesimpulan** - Ringkasan hasil dan rekomendasi

### Format

Dokumen tersedia dalam format Microsoft Word (.docx) dengan tabel dan format yang lengkap, siap untuk dibuka di Microsoft Word atau aplikasi pengolah dokumen lainnya.
